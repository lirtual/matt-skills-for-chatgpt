# Matt Skills for ChatGPT

Unofficial, community-maintained ChatGPT adaptation of [Matt Pocock's skills](https://github.com/mattpocock/skills).

**Status:** design/specification only. No plugin has been created, published, or installed by this repository.

The agreed architecture is a skills-only personal plugin, with upstream content pinned to a reviewed Git commit. Design documents are tracked in [PR #1](https://github.com/lirtual/matt-skills-for-chatgpt/pull/1), and the formal specification is [Issue #2](https://github.com/lirtual/matt-skills-for-chatgpt/issues/2). The installed Matt Skills Curated plugin stays untouched until the replacement is created, installed, and passes real acceptance checks.

See `CONTEXT.md`, `DECISIONS.md`, `docs/adr/`, `UPSTREAM.md` and the source license for the recorded decisions. No automated upstream sync or deployments are enabled.
