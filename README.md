# Matt Skills for ChatGPT

Unofficial, community-maintained ChatGPT adaptation of [Matt Pocock's skills](https://github.com/mattpocock/skills).

**Status:** design/specification only. No plugin has been created, published, or installed by this repository.

The agreed architecture is a skills-only personal plugin, with upstream content pinned to a reviewed Git commit. Planning documents and an implementation spec will be proposed through pull requests and issues. The installed Matt Skills Curated plugin stays untouched until the replacement is created, installed, and passes real acceptance checks.

See the upcoming design PR for `CONTEXT.md`, `DECISIONS.md`, `docs/adr/`, `UPSTREAM.md` and the source license. No automated upstream sync or deployments are enabled.
